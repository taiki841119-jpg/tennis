# テニス乱数表

ダブルス(1コート)のペア・対戦相手を乱数で決める、スマホ向け Web アプリです。

## 機能
- ペアと対戦相手を乱数で決定(出場回数・連続休み・過去のペア/対戦相手の偏りを抑える)
- 数試合分の「乱数表」を先に作成。参加状況が変わると自動で作り直し
- 途中参加・休憩・復帰・途中抜けに対応(復帰/途中参加者が連続出場で有利にならないよう補正)
- 番号クジ機能
- 名前を直接入力、または名簿から選んで参加
- グループ単位の名簿・合言葉(簡易パスワード)。複数端末・複数グループの同時利用

## 画面構成
- `index.html` : トップ画面(かんたん版 / 名簿・グループ版を選ぶ)
- `simple.html` : かんたん版(ログイン不要・その端末だけ)
- `group.html` : 名簿・グループ版(合言葉あり・複数端末で共有)

## まず試す(設定不要)
`index.html` をブラウザで開いて選びます。グループ版は設定が空のままなら「ローカルモード」で動きます(データはその端末内のみ)。

## 公開手順(複数端末で共有)

### 1. Supabase(無料)
1. https://supabase.com でプロジェクトを作成
2. SQL Editor で [supabase.sql](supabase.sql) の内容を貼り付けて Run
3. Project Settings > API から `Project URL` と `anon public` キーを控える
4. [config.js](config.js) に貼り付ける

> anon キーは公開前提のキーです。表は RLS で直接アクセス不可にしてあり、
> 「グループ名+合言葉」を知る人だけが関数経由で読み書きできます。

### 2. GitHub Pages
1. このフォルダを GitHub リポジトリに push
2. Settings > Pages > Branch を `main` / root に設定
3. 発行された URL をスマホで開く(ホーム画面に追加すればアプリ風に使えます)

## 注意
- ニックネーム以外の個人情報は入力しないでください(簡易パスワードのため)
- 合言葉の総当たり対策は入れていません。推測されにくい合言葉にしてください
